# דלתא מחשבים — כלי טכנאים נייד

מאגר זה מיועד **להורדת התוכנה ולעדכונים חתומים בלבד**. קוד המקור ותהליכי הפיתוח מנוהלים במאגר נפרד ואינם מתפרסמים כאן.

## הורדה

[הורדת הגרסה האחרונה למחשבי Windows x64](https://github.com/raghebdcc/delta-tech-toolkit/releases/latest/download/DeltaTech.exe)

[כל הגרסאות והסבר השינויים](https://github.com/raghebdcc/delta-tech-toolkit/releases)

הורד את הקובץ והפעל אותו רגיל תחת המשתמש שבו מטפלים. פעולות שדורשות הרשאת מנהל יבקשו אותה בנפרד. אין צורך בהתקנת סביבת ‎.NET‎ בנפרד. התוכנה שומרת דוחות והגדרות מקומית.

## עדכון מתוך התוכנה

בחר **עדכון** בתוכנה. אין צורך בחשבון GitHub, באסימון גישה או בהרשאה למאגר הקוד. כתובת העדכונים המקורית נשמרה ולכן גרסאות קיימות ממשיכות להשתמש בה.

כל גרסה מכילה שלושה קובצי הפצה: `DeltaTech.exe`, `update.json`, `update.sig`. לפני התקנה התוכנה מאמתת את חתימת המפרסם ואת גיבוב קובץ התוכנה. הקובץ הקודם נשמר לצורך חזרה לגרסה קודמת. חתימת העדכונים נפרדת מחתימת קוד מסחרית של Windows.

## כלים עיקריים

- בדיקה מהירה של זיכרון, טמפרטורות זמינות, דיסקים, סוללה ושטח פנוי.
- דוח ביקור בעברית לשמירה ולהדפסה.
- אבחון רשת, מיפויי כוננים, כלי דואר ומדפסות.
- פעולות מסודרות לפי קטגוריות, עם תיאור השפעה ובקשת הרשאות לפי הצורך.

איסוף שהושלם אינו אישור תקינות חומרה. נתונים חסרים ומגבלות תמיכה מפורטים בתוצאות. יש לעבור על הממצאים לפני מסירה ללקוח.

ארכיוני המקור ש-GitHub מציעה במאגר זה מכילים את הוראות ההורדה בלבד, ולא את קוד התוכנה. אין לשמור במאגר דוחות לקוחות, אסימוני גישה או מפתחות חתימה פרטיים.
